# Experiment editor

On 22nd August 2024 a new version of the experiment editor was released, which is a complete rewrite that more directly represents the actual file format. It is based on [Blockly](https://github.com/google/blockly) with its familiar puzzle-style graphical interface.

You can find a tutorial on Youtube: [Tutorial in English](https://youtu.be/0ExKwwS--uY) \| [Tutorial in German](https://youtu.be/Vb-kymhA4jU)

To learn more about specific elements in the editor, try to reach the documentation vie right-click-\>help or search for the corresponding element in the [phyphox file format](../file-format/index.md) documentation.
